# Graffiti Russia — главная страница

Новый дизайн главной страницы [graffitirussia.com](https://graffitirussia.com/): статичная вёрстка на HTML, CSS и JavaScript без фреймворков и сборки.

## Что внутри

```
.
├── index.html            # разметка страницы
├── assets/
│   ├── css/style.css     # все стили
│   ├── js/main.js        # слайдеры, меню, анимации, чат-ассистент
│   └── img/
│       ├── logo.svg      # логотип из Figma (в index.html он встроен инлайном — для анимации букв)
│       └── favicon.svg
├── .nojekyll           # чтобы GitHub Pages отдавал файлы как есть
├── .editorconfig
└── .gitignore
```

## Блоки

1. **Первый экран** на 100 % высоты окна: логотип с анимацией по буквам, меню, заголовок, бесконечный слайдер работ. Курсор оставляет брызги краски (только десктоп).
2. **Шапка** появляется при скролле: логотип уменьшается и встаёт по центру, меню сгруппировано («Услуги» — мегаменю, «Проекты», «Компания», «Обучение»), телефон, VK, «Обсудить проект». До 1200 px — бургер-меню.
3. **О компании** — заголовок, описание, кнопка «Подробнее».
4. **Команда** — 4 человека в ряд, стрелки и счётчик; 3 / 2 / 1 на меньших экранах.
5. **Преимущества** — три карточки с иконками.
6. **Чат-ассистент** «Рассчитать стоимость» — плавающая кнопка в правом нижнем углу.

Минимальный размер шрифта — 18 px. Блоки появляются плавно из размытия. Если в системе включено «уменьшение движения», анимации отключаются.

## Запуск локально

Достаточно открыть `index.html` в браузере. Или поднять локальный сервер:

```bash
npx serve .
# или
python3 -m http.server 8080
```

## Публикация на GitHub

```bash
git init
git add .
git commit -m "Новая главная страница Graffiti Russia"
git branch -M main
git remote add origin https://github.com/<аккаунт>/<репозиторий>.git
git push -u origin main
```

Чтобы сайт открывался по ссылке, включите **GitHub Pages**: *Settings → Pages → Source: Deploy from a branch → main / (root)*. Через минуту страница будет доступна по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Что нужно доделать перед запуском

- **Фото.** Работы в слайдере и фото команды сейчас подгружаются напрямую с `graffitirussia.com/wp-content/uploads/…` — это оригиналы, они могут весить по несколько мегабайт. Лучше сделать копии ~1000 px в WebP, положить в `assets/img/` и поменять пути в `assets/js/main.js` (массивы `works` и `team`).
- **Чат-ассистент** — это сценарий-демо: вопросы и ответы прописаны в `main.js` (массив `flow`), заявка никуда не отправляется. Место для отправки помечено комментарием `TODO` в функции `userSays` — туда подключается сервер, CRM, Telegram-бот или настоящий AI.
- **Формы и ссылки** «Обсудить проект», «Подробнее» и пункты меню ведут на страницы текущего сайта `graffitirussia.com`.
- **Шрифты.** Helvetica Neue берётся из системы (на Windows вместо неё будет Arial). JetBrains Mono подключается с Google Fonts — для работы в РФ без внешних запросов его можно скачать и подключить локально.
